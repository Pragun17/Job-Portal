# JobPortal - Flask Web Application (Naukri Clone)

A feature-rich job portal web application built with Flask, Flask-SQLAlchemy (ORM), Flask-Login, and Bootstrap 5.

## Features
- **Role-Based Authentication**: Register and login as either a Job Seeker (Employee) or Recruiter (Employer).
- **Employer Portal**: Post new jobs, view posted jobs, and check candidate applications and resumes.
- **Job Seeker Portal**: Search jobs by title/keywords and location, view job details, and apply with 1 click. Track application statuses.
- **Clean Responsive UI**: Styled professionally using Bootstrap 5 and FontAwesome.

## Setup & Installation

1. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # On Windows
   source venv/bin/activate  # On macOS/Linux
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python app.py
   ```

4. Open your browser and navigate to: `http://127.0.0.1:5000`
